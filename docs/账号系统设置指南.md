# 账号系统设置指南（Supabase）

本站的「账号 + 云端笔记」用 [Supabase](https://supabase.com)（免费档即可）实现，**无需自己写后端、无需迁移托管**，继续留在 GitHub Pages。按以下步骤配置即可启用；在配置完成前，站点会自动降级为「浏览器本地笔记」，一切照常。

---

## 1. 创建 Supabase 项目
1. 注册并登录 <https://supabase.com>。
2. New project → 填项目名、设置数据库密码（自己保存）、选区域 → 创建（约 1~2 分钟就绪）。

## 2. 建表 + 开启行级安全(RLS)
进入项目 → 左侧 **SQL Editor** → New query → 粘贴并运行：

```sql
-- 笔记表：id 用前端生成的字符串，user_id 自动取当前登录用户
create table if not exists notes (
  id            text primary key,
  user_id       uuid not null default auth.uid() references auth.users(id) on delete cascade,
  chapter_id    text not null,
  chapter_title text,
  quote_text    text not null,
  note_text     text default '',
  color         text,
  occ           int,
  created_at    timestamptz default now()
);

-- 开启行级安全：每个人只能读写自己的笔记
alter table notes enable row level security;

create policy "own notes - select" on notes for select using (user_id = auth.uid());
create policy "own notes - insert" on notes for insert with check (user_id = auth.uid());
create policy "own notes - update" on notes for update using (user_id = auth.uid()) with check (user_id = auth.uid());
create policy "own notes - delete" on notes for delete using (user_id = auth.uid());
```

> RLS 是安全关键：即使 anon key 公开，别人也只能访问**自己**账号下的行。

## 3. 开启邮箱登录
- 左侧 **Authentication → Providers → Email**：确保 Email 已启用（默认开启）。
- 新账号默认需要**邮箱确认**：
  - 想先快速自测，可在 **Authentication → Providers → Email** 里暂时关闭 “Confirm email”（上线前建议再打开）。
- 把本站地址加入白名单：**Authentication → URL Configuration → Site URL / Redirect URLs** 填 `https://jackielam.github.io/aap-baby-guide/`（本地自测再加 `http://localhost:8000`）。

## 4. 填入前端配置
项目 → **Settings → API**，复制两项，填进仓库的 `assets/js/config.js`：

```js
window.SUPABASE_URL = "https://xxxxxxxx.supabase.co";      // Project URL
window.SUPABASE_ANON_KEY = "eyJhbGciOi...（anon public key）";
```

> `anon public` key 可以公开放前端，这是 Supabase 的设计；数据隔离靠上面的 RLS。
> 不要把 `service_role` key 放进前端（那是管理员密钥）。

提交推送后，GitHub Pages 更新，顶栏就会出现「登录 / 注册」。

---

## 工作原理（给维护者）
- `assets/js/config.js`：放 Supabase URL/key；占位未填时账号系统自动禁用。
- `assets/js/auth.js`：建 Supabase 客户端、登录弹窗、监听登录态；
  - 登录后 → 拉取该用户 `notes` → 调 `window.setNotesMode("cloud", list)` 切到云端；
  - 登出 → `window.setNotesMode("local")` 切回本地；
  - 首次登录会询问是否把本机已有笔记迁移到账号。
- `assets/js/app.js`：笔记读内存缓存（渲染同步），写入按模式走本地或 `window.CloudNotes`。

## 常见问题
- **登录没反应/报错**：检查 `config.js` 是否填对、浏览器控制台报错；确认 Site URL 白名单。
- **注册后不能登录**：邮箱确认未完成（去邮箱点确认链接），或关闭 Confirm email 后重试。
- **笔记没同步**：确认已登录（顶栏显示邮箱）、RLS 策略已创建。
- **未配置时**：笔记走浏览器本地，不跨设备——这是预期降级行为。
